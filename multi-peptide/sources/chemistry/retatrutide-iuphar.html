IUPHAR/BPS Guide to Pharmacology (GtoPdb) is an expert-curated database of pharmacological data, which we want to keep open-access for all. However, maintaining and updating GtoPdb is not free. In order to help support our future sustainability we now ask that users register to access GtoPdb so that we can collect accurate user data, which helps us improve our services, security and website performance. Registering is simple, just click the button above.

Commercial organisations that use GtoPdb must pay access-fees which support the maintenance, curation and sustainability of the resource. Please read our sustainability statement for more information.

If you have any questions about accessing GtoPdb, please get in touch with us. For more information on GtoPdb please see our about page.
